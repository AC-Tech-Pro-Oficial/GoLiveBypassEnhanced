Como montar uma VPS (saída estável)
  1. Alugue um VPS barato fora do Brasil (Chile, EUA, etc.).
  2. Instale um SOCKS5 — ex.: dante, 3proxy ou Shadowsocks.
  3. Cole aqui socks5://IP:porta (com usuário se pedir login).
  4. Clique em Testar conexão: tem que abrir túnel até o gateway do Discord.
  5. Na call, não force a região Brazil — a mídia BR ainda pode derrubar a tela.

Isso não é um servidor local de streams: o Discord só libera o Go Live se o gateway sair com IP de outro país. A VPS é a sua saída, estável e sua.
