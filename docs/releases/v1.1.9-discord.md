# 🚀 GoLiveBypass 1.1.9

Release com TUI nova nos instaladores, bypass mais esperto no Tor, e GUI
mais resiliente.

> Sem mudança de protocolo: a sinalização continua em `*.discord.gg` por
> SOCKS5 e o WebRTC segue direto pela sua conexão.

---

## 🖥️ Instaladores de terminal — TUI estilo OpenCode

Os 4 instaladores (PowerShell + bash, Windows + Linux) agora abrem uma
TUI artesanal quando o terminal permite: caixas centralizadas, setas /
mouse, navegação por teclado (`j` / `k` / Enter / Esc). Sem dependência
extra, sem binário extra.

Caí automaticamente para os menus `[1]/[2]/[3]` em:
- terminais sem TTY
- flags `-Yes/--yes` (automação)
- `cmd` / conhost clássico (sem suporte a VT)

**Outros ganhos nos instaladores:**
- Detecta **Equibop / Vesktop / Legcord** (AUR e flatpak) — antes só o
  Discord oficial era achado.
- **Tor automático** nos 4 scripts: baixa Expert Bundle 13.5, confere
  SHA-256, extrai e registra serviço persistente (systemd user/system no
  Linux, Run key no Windows) na 9060.
- **Auto-report de bugs** via API — abre issue sozinha quando algo quebra
  de verdade (credenciais e tokens são redacted). Erros de uso não
  reportam.

## 🛡️ Bypass — checagem de país do exit do Tor

~37 relays Tor (0,4% do total) saem pelo Brasil. O servidor do Discord
bloqueia Go Live com IP BR, e o bypass não tinha como saber — o log dizia
"túnel aberto" mas o usuário ficava sem Go Live, sem aviso.

Agora o `golivebypass.js` confere o país do exit (cache de 8 min, 1
consulta por circuito) e **recusa** exits em BR. Se a recusa persistir,
**segura o gateway** em vez de abrir direto pelo IP brasileiro.

## 🔧 GUI — mais resiliente

- **Watchdog do Tor**: se o daemon da 9060 morre ou trava no meio da
  sessão (ISP, sleep, wi-fi), ressuscita o mesmo Tor. Aviso via toast —
  sem reload automático, porque reconexão de gateway no meio de Live
  pode travar vídeo.
- **Saída manual volta sozinha**: medido ao vivo, uma proxy privada ficou
  fora por 48 min e voltou do lado do servidor. Antes o app só
  redescobria reabrindo o Discord. Agora tenta a cada ~90s, fora de
  chamada/Live.
- **Botão "Testar"** agora aceita range `host:portaInicial-portaFinal`.

## 📦 Como atualizar

- **GUI Windows**: auto-update via GitHub Releases. Manual: baixe
  `GoLiveBypass-Portable-1.1.9.exe` e substitua.
- **Plugin Vencord/Equicord**: auto-update pelo userplugin já publicado.
- **Instaladores de terminal**: baixe o instalador da release e rode
  novamente.
