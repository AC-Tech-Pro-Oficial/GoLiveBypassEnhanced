# GoLiveBypass 1.1.9

Release focada em **TUI dos instaladores de terminal**, **estabilidade da
saída Tor** e **heurística do bypass**. Sem mudança de protocolo: o bypass
injetado continua o mesmo formato `*.discord.gg` por SOCKS5 + WebRTC direto.

> **Como atualizar**
> - **GUI Windows**: auto-update via GitHub Releases (5 suites, 158 testes).
>   Se preferir manual, baixe `GoLiveBypass-Portable-<ver>.exe` e substitua.
> - **Plugin (Vencord/Equicord)**: auto-update pelo userplugin já publicado
>   (assetName fixo, sempre baixa a versão mais recente).
> - **Instaladores de terminal** (ps1/sh): baixe o instalador da release e
>   rode novamente — ele atualiza in-place.

## Destaques

### 🖥️ Terminal — TUI estilo OpenCode nos 4 instaladores
Os instaladores PowerShell e bash ganham uma TUI artesanal (sem dependência,
sem binário extra) com caixas centralizadas, navegação por setas, mouse SGR
no Linux e teclado (setas / `j` / `k` / Enter / Esc) no Windows.

Caí automaticamente para os menus `[1]/[2]/[3]` quando o terminal não tem
TTY, quando `-Yes/--yes` foi passado, ou quando o console não suporta VT
(`cmd` / conhost clássico). Em Windows Terminal, VS Code ou qualquer
emulador com ANSI funciona a TUI cheia.

- **Auto-detecção de Equibop / Vesktop / Legcord** (AUR e flatpak):
  `/usr/share`, `/usr/lib`, `/usr/lib64`, `/opt` e `~/.local/share`. Antes
  só o Discord oficial era encontrado.
- **Tor automático nos instaladores**: baixa Expert Bundle 13.5, confere
  SHA-256, extrai e registra serviço persistente (systemd user/system no
  Linux, Run key do usuário no Windows) na porta 9060.
- **Auto-report de bugs** via API: ao falhar, monta diagnóstico sanitizado
  (credenciais, tokens e proxy pessoal são redacted) e abre issue no
  repositório. Erros de digitação do usuário não reportam.
- **Filtros de ruído no auto-report**: "Cancelado.", "O Discord não
  fechou…", "Ctrl+C cancelou", dependência faltando, CLI digitada errada.
  5 issues desnecessárias que abriram (#65-#69) ficam resolvidas.

### 🛡️ Bypass — checagem de país do exit do Tor
~37 relays Tor (0.4% do total) saem pelo Brasil. O servidor do Discord
bloqueia Go Live com IP BR — a sessão ficava presa: o bypass dizia
"túnel aberto" mas o usuário via Go Live bloqueado sem nenhuma indicação
do motivo.

Agora o `golivebypass.js` consulta o país do exit (cache TTL 8 min,
1 consulta por circuito) e **recusa** exits em BR. Se a recusa persistir,
segura o gateway em vez de abrir direto pelo IP brasileiro.

```
Antes: Tor encontrado na porta 9050 (geo nao verificada em modo tor)
Depois: Tor encontrado na porta 9050, saida em LT (aceita)
Com BR forçado: Tor na porta 9050 recusado: saida em BR +
                 segurando o gateway (sem saida direta)
```

### 🔧 GUI — watchdog do Tor e auto-retorno da saída manual
- **Watchdog do Tor** (`golive-gui/electron/torwatchdog.ts`): detecta o
  daemon morto ou travado no meio da sessão e ressuscita o **mesmo** Tor
  (nunca troca de saída — respeito ao AGENTS.md). Aciona após 2 falhas
  seguidas com heartbeat de 30s. Aviso "Tor reiniciou" via toast — sem
  reload automático (reconexão de gateway no meio de Live pode travar
  vídeo até Ctrl+R).
- **Saída manual volta sozinha** depois de cair: medido ao vivo com proxy
  privada no Principal, uma saída ficou fora por 48 min e voltou do lado
  do servidor. Antes, o app só descobria reabrindo o Discord. Agora o
  batimento tenta a cada ~90s, **fora de chamada ou Live em andamento**
  para não arriscar reconectar o gateway com transmissão no ar.
- **Botão "Testar" aceita range** `host:portaInicial-portaFinal` — testando
  uma porta sorteada, igual à ativação. Antes recusava com "Formato
  inválido" mesmo com o endereço correto.
- **3 bugs do retorno manual corrigidos** (revisão pré-merge do PR #64):
  `tryReturnToManual` agora respeita `routeMode === "tor"`,
  `isManualAddress` alinhada com `parseProxy` para range inválido, e a
  troca silenciosa não dispara mais o banner "Ctrl+R" espúrio.

### 🚀 CI — auto-update Onda 2 (`release-assets`)
Novo job publica 4 assets extras na release em paralelo com os builds da
GUI:
- `goLiveBypass-vencord.zip` — userplugin Vencord com `manifest.json`
  (`assetName` fixo, sempre baixa a versão mais recente independente da
  tag).
- `goLiveBypass-vencord.zip.sha256` — hash do zip.
- `GoLiveBypass-<ver>-bypass.js` — bypass standalone puro.
- `GoLiveBypass-<ver>-bypass.js.sha256` — hash do bypass.

## Melhorias pequenas
- Cor `Invoke-CheckUpdate` em `Write-Host -ForegroundColor` (não quebrava
  mais em `installer.ps1 -Mode CheckUpdate`).
- BOM UTF-8 nos `ps1` para o PowerShell 5.1 ler acentos e box-drawing
  sem parser quebrado.
- `tui_menu` centralizado no meio do terminal via `stty size` + `tui_cursor`.
- `tui_is_interactive` reduzido para só `[ -t 0 ]` (antes `-t 1` quebrava
  em pty/emuladores).
